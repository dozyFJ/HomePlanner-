# WolfCraft Home Planner

Настольный планировщик одноэтажного дома на Rust. Редактор строит 3D-превью из того же проекта, который открыт на чертёжном листе. Рендеринг использует `WorldRenderer`, `GpuContext` и интерфейсный рендерер WolfCraft.

## Запуск

Установите стабильный Rust и драйвер с поддержкой Vulkan на Linux или DirectX 12 на Windows.

```sh
cargo run --locked
```

1. В режиме **Лист · 2D** выберите «Комната» и отметьте два противоположных угла на сетке 0,5 м. Инструмент «Стена» добавляет перегородки двумя щелчками.
2. Выберите «Дверь» или «Окно» и щёлкните по стене. Поставьте кровать, стол или диван. Чекбокс поворачивает следующую мебель на 90°.
3. Откройте **Обзор · 3D**. Перетаскивание поворачивает камеру, колесо меняет масштаб. «Срез стен» открывает интерьер.
4. Введите имя файла и нажмите «Сохранить» или «Открыть». Кнопка «Загрузить пример» показывает готовую планировку. Последнее изменение можно отменить.

Лист первой версии имеет размер 24 × 16 м. Формат проекта — JSON.

```sh
cargo test --locked
cargo run --locked -- --smoke-test
```

Для графического smoke-теста нужен рабочий дисплей и адаптер Vulkan или DirectX 12. Тест открывает пример и рендерит кадры 2D и 3D.
